# The Ocean’s Memory Palace

### Pacific Climate Change — Interactive Data Storytelling

The Ocean’s Memory Palace is an interactive data visualization project that explores climate change across the Pacific region through immersive ocean environments, scroll-based storytelling, and dynamic data visualizations.

The project combines Data Analytics, Data Visualization, and Digital Storytelling to communicate environmental changes through an engaging, accessible, and visually meaningful experience.

## Live Website

Explore the interactive experience:

**https://feyshakamilaa.github.io/pacific-climate-memory/**

## Key Features

- **Interactive Data Storytelling** — An immersive narrative exploring climate change across the Pacific region.
- **Scroll-Based Experience** — Visual transitions that guide users through the environmental narrative.
- **Dynamic Data Visualization** — Interactive charts presenting climate-related information.
- **Immersive Ocean Environments** — Ocean-inspired visual experiences that connect scientific data with environmental storytelling.
- **Climate Awareness** — Accessible presentation of environmental issues through data-driven narratives.

## About the Project

This project was developed as part of the Pacific Dataviz Challenge 2026, combining data science, creative visualization, and environmental storytelling to communicate the impacts of climate change.

The project aims to make complex environmental information more accessible, engaging, and meaningful to a broader audience.
